Welcome to Ticketer.

Ticketer is a modern ticket management system built specifically for Discord communities. It combines a powerful Discord bot with a structured web dashboard, giving you full control over how your server handles support, applications, reports, and internal requests.

Whether you run a small community or manage a large support team, Ticketer is designed to scale with you.

## Prefix

The prefix for Ticketer is `/`. You can type `/help` for a list of commands or go to our [<u>commands page</u>](https://ticketer.bot/commands).

## What is Ticketer?

Ticketer allows you to:

- Create and manage structured support tickets using Panels
- Assign staff roles and control permissions
- Automatically generate and store transcripts
- Let AI handle common questions and responses
- Configure everything through a clean web dashboard

## Is Ticketer free?

Yes! Ticketer offers a free plan with generous limits, allowing you to get started without any cost. We also have premium plans with additional features and higher limits for larger communities.

<Info>
  If you want to see the full list of features and compare plans, check out our [<u>pricing page</u>](https://ticketer.bot/pricing).
